# Visualize resource license

The skill entrypoint, standalone assets, widgets, rendering scripts, and parameter-control runtime are part of the visualize plugin and are licensed under the Apache-2.0 license declared by that plugin. The repository root is licensed under AGPL-3.0; plugin-level license declarations remain in effect.

The browser libraries in `assets/vendor/` retain their separate licenses: Floating UI Core and DOM use MIT; Lucide and D3 use ISC. Each library's license text is stored beside its script and recorded in `assets/vendor/manifest.json`.
