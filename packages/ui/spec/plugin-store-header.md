# 插件市场顶部栏

> 目标：把插件市场从「大标题 + 副标题行 + 整宽搜索 + 分段行」压缩为两行顶部结构，
> 与用户确认的视觉稿一致，同时保持现有筛选、搜索和动作入口的行为不变。

## 范围

- `packages/ui/src/settings/PluginStorePage.tsx` 的列表视图头部：标题与动作同排。
- `packages/ui/src/settings/PluginStoreListView.tsx` 的筛选行：分段靠左，搜索靠右。
- 不改变详情视图、市场源对话框、添加菜单内容和安装/启停逻辑。

## 布局规则

| 区域   | 规则                                                                                      |
| ------ | ----------------------------------------------------------------------------------------- |
| 第一行 | 左侧标题 `插件市场`（24px）；右侧依次为刷新、市场源、添加（描边）、管理已安装（主按钮）。 |
| 第二行 | 左侧为「通用 / 个人 / 游戏开发」分段；右侧为搜索框。                                      |
| 搜索框 | 工具栏容器宽度 ≥ 680px 时固定 320px 并右对齐；更窄时换行铺满，左右边缘与内容列对齐。      |
| 间距   | 标题行与筛选行使用页面统一间距；列表内容与筛选行之间 24px。                               |
| 副标题 | 列表视图不再渲染可见副标题行，文案 key 保留以兼容翻译。                                   |

## 状态所有权

- 搜索词、分段和游戏筛选仍由 `PluginStorePage` 持有并下传，`PluginStoreListView` 不新增镜像状态。
- 刷新、市场源、添加、管理已安装继续调用页面既有回调，不新增接口、持久化或网络请求。
- 安装/启停事实仍由 `pluginManagementStore` 持有；本轮只调整 ui 布局。

## 验收场景

1. 桌面宽度下标题与四个动作在同一行垂直居中，且不换行溢出。
2. 分段与搜索在宽内容列同一行：分段左对齐，搜索右对齐且宽度约 320px。
3. 内容列变窄（如 640 / 390px 视口）时搜索换行铺满，分段与搜索都不溢出。
4. 分段切换、搜索过滤、添加菜单、市场源和插件管理入口行为与改动前一致。
5. 中英文与明暗主题下顶部不出现横向滚动。

浏览器回归入口：`node packages/ui/test/gameDevelopmentPlugins.e2e.mjs`（需要本机 Chrome），
其中包含分段/搜索同排、固定宽度和窄容器换行的几何断言。
