# 参考图建模与剪影验收

## 选路线

使用 `/blender-from-reference` 时先看本轮附图、用户路径和明确要求。读取实际像素，选择一张主参考。若图像或影响造型的约束缺失，先说明具体缺少什么。单张图无法证实的背面、深度和遮挡标记为推定，并在对照时保留说明。

第一笔写入前通过 `blender_doctor`，再用 `get_addon_status` 核对实际可用能力，读取当前场景与已有资产。优先评估项目内可编辑基底，能沿用时先保存工作副本。需要图生 3D 时，使用支持当前参考输入且用户已授权的服务，先检查结果的可编辑性和参考相似度。生成服务未启用或未获授权时，直接用可行的本地方案。只能做到草模时，完成有用的草模和可验证的部分，在交付中说明局限。只有缺少无法替代的关键输入或确实需要用户处理的授权、连接等阻塞时才询问。

本工作流通过已配对的 Blender MCP 改场景。读取参考、已有文件和运行隔离复读可以使用本地工具。后台 Blender 全量重建会跳过场景预检和阶段成果，遇到 MCP 不可用时按 doctor 恢复。

## 草模自检

1. 先从参考选择能比的取景。主机位尽量对齐人物或物体的朝向、取景范围、相机高低和透视。补一张侧面或斜侧视图检查体积。视角与参考差异过大时，先修机位再评估几何。
2. 资产先搭大形。角色核对头身比例、肩和胯的方向、重心与脚的位置、膝肘和手势，再核对头发及服装的外轮廓。道具与场景先核对尺度、透空、主要体块和相对位置。先选 3–5 个会影响辨识度的特征。
3. 完成姿势和主要形体后，保存 `.blend` 工作副本，用 `look(shading="solid")` 或对应相机渲染草模。由 Agent 对照参考、局部修正并复看。每个特征记录 `通过`、`需修正` 或 `未验证` 和可见证据。优先修轮廓、肩胯、重心和手脚，避免用材质掩盖形体差距。
4. 自检后直接继续适合当前形体的细化。若一轮局部修形后仍有差距，完成可独立验证的工作并把剩余问题带到交付。用户明确要求分阶段验收时，提交对照及草模文件并等待反馈；用户只要求草模时，以草模为最终交付。

## 通过后细化与保存

- 保留通过的剪影与姿势，按参考局部修脸、发束、服饰层次和材质。继续复用相同取景对照，用侧视图检查体积和穿插。交付时一起提供实际预览、原图、保存文件，以及外观与结构检查的结果。
- 带渲染的 `.blend` 在保存前把确认过的交付机位赋给 `bpy.context.scene.camera`，按目标对象或集合运行 `inspect_asset(..., require_camera=True)`。在隔离环境复读，核对活动相机与交付机位一致，并检查需要随文件交付的贴图。导出 GLB 时单独复读形体、材质、动画等用户要求的内容。只有 Blender 预览验证通过时，按实际覆盖说明。
