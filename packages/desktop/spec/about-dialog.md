# 桌面端“关于”弹窗

## 产品规则

- 从主界面帮助菜单打开“关于 KayingCode”时，显示独立的模态窗口；其面板在浅色和深色系统主题下都与背后的工作区清晰区分。
- 左上角展示与桌面应用一致的 KY 图标，使用桌面构建的 `icon.png`；开发环境和安装包分别从现有应用图标路径读取。
- 应用名、产品版本、版权、Apple Silicon 提示及确定按钮沿用当前本地化规则。确定、Enter 或 Escape 关闭窗口。

## 所有者与接口

- Electron Main 的 `showAboutDialog` 拥有窗口生命周期，并读取图标与构建元数据。
- `createCustomAboutDialogHtml` 仅接收文字和图标 data URL，负责静态内容与主题样式；不保存业务状态，也不访问文件系统。
- 现有帮助菜单命令是唯一入口，不新增跨包协议。

## 验收场景

1. 深色和浅色模式中，弹窗均有不透明面板、可见边框、可读文字和按钮。
2. 图标直接来自应用 `icon.png`，没有弹窗专用的手绘 KY 路径。
3. 中文和英文版本信息正常显示；图标或文字不能注入 HTML。
4. 确定、Enter 和 Escape 均关闭弹窗。
