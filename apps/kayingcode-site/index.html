内置 / TAPTAP MAKER

你的项目，
接着往前做。

从项目读取、诊断到构建和发布准备，让 TapTap Maker 工具进入同一工作台。已有 three.js 游戏，也能按模块转写，再对照原版验证。

  1. 01

    读取项目

    连接项目与本地工作区，从已有内容继续。

  2. 02

    实现 / 转写

    按模块推进，让每次修改都可以检查。

  3. 03

    双预览验证

    在同一视口对照原版与目标结果。

  4. 04

    确认发布

基于 ZCODE

熟悉的底座。
自己的工作方式。

保留 ZCode 的 Agent 工作台，把游戏工具接进来。模型怎么选、工具怎么接，由你决定。

04 / GET STARTED

打开项目，开始下一轮。

从源码运行桌面工作台。准备 Git、Node.js 24.14.0 与 Bun 1.3.14；版本以仓库的 mise.toml 为准。

桌面工作台 / 推荐游戏开发01 ↗ 
bun run bootstrap
bun run dev:desktop
浏览器工作台02 ↗ 
bun run dev:web
终端 Agent03 ↗ 
bun run --filter @zcode/cli dev

05 / FAQ

开始之前

项目数据和模型请求在哪里？+

项目与会话保存在本机。使用模型时，所需上下文会发送到你配置的模型端点；TapTap 工具也会访问对应平台服务。

游戏预览和视觉验证支持哪些入口？+

原生游戏预览、双预览视觉对比和本机控制以本地 Desktop 为主。Web 与 CLI 提供各自的工作入口。

能自动发布到 TapTap 吗？+

工具可辅助项目、诊断、构建与发布准备。平台登录、授权、结果验证和最终发布确认由你完成。
