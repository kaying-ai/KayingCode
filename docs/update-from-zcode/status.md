## 明确的平台边界

- 文件系统源文件的打开与完整工作区文件浏览仍受移动白名单限制，入口给出需在 Host 查看提示；工具内文本/patch 用共享 CodeViewer，附件媒体走 V4 read。不把完整 Desktop Root 的所有功能视作可用。
- H5 主题/语言与原生各自管理；没有原生后台未读/通知桥。网页停用或断网不会自动创建原生 Agent 链路。
- 第一次迁移使用有效新配对码；后续同一 Bot/code 使用网页凭据恢复，新码重新配对。旧原生 token 与档案保留，网页不导入。
- 发布需先升级两种 Relay 对应部署、配置 `RELAY_WEB_CLIENT_URL` 并发布完整 Web dist。Windows 需 Windows 工具链；OH 本机静态检查已通过，签名 HAP/设备运行未执行。
