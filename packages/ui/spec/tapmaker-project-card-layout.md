# 我的 TapMaker 游戏卡片

- 列表按内容区宽度排列。达到 54rem 显示三列，达到 36rem 显示两列，其余宽度单列铺满。网格居中，最大外宽 64rem，双列和三列布局额外保留两侧各 2rem 留白。卡片间距与内边距为 16px。
- 游戏名和置顶标记放在标题区，下一行左侧为类型及阶段，右侧为最近活动日期。项目 ID 仅供内部识别项目及恢复操作使用。底部用分隔线区分本地路径或云端状态与对应操作，操作按钮右对齐。
- 长游戏名和路径可截断，保留完整 `title`。日期和操作按钮不受长文本挤压。缺少类型、阶段或日期的项目继续正常展示。
- `TapMakerProjectsPage` 负责布局，`useTapMakerProjects` 继续提供列表和操作状态。打开、恢复、刷新与授权沿用原有回调、平台限制和失败提示。

## 验收

- 1536px 桌面视口（含 256px 侧栏）三列，1080px 桌面视口两列，390px 手机视口单列。同排操作区对齐，卡片正文与悬停文字均不显示项目 ID，日期仍可见。
- 1536px 视口中三列卡片等宽，单张卡片宽度不超过 320px，网格两侧留白对称。手机沿用页面边距。
- 中文长游戏名、英文操作按钮及长本地路径同时存在时，页面无横向溢出，完整值可查看，按钮保留完整文本与原有操作能力。
