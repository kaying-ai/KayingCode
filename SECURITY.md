# 安全问题报告 / Security reporting

如 GitHub 仓库的 Security 页面提供 **Report a vulnerability**，请使用该私密入口。也可将报告私密发送至 **service@kayingai.com**。请说明受影响版本、复现步骤、影响范围和必要的最小证据。公开 Issue 只适合提交可公开的问题。

Use **Report a vulnerability** on the repository's Security page when available, or email **service@kayingai.com** privately. Include the affected version, reproduction steps, impact, and only the minimum evidence needed. Use public issues for information that can be shared publicly.
