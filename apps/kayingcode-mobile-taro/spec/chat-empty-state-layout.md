# 小程序会话页空态布局

## 产品规则

- 新建会话的消息流为空时，引导语“输入消息开始新会话”显示在顶部栏与输入框之间的消息区域中央。
- 已有会话没有消息时，“暂无消息”沿用同一居中空态；发送中或已有消息时不再显示空态引导。
- “内容由AI生成”标识继续固定在消息区域顶部。空态引导使用独立的垂直布局，不能与标识重叠。
- 空态只改变文案位置，不改变发送、滚动、历史加载或 AI 标识的状态与事件路径。

## 状态与接口

- `pages/chat/index.tsx` 继续根据消息行和 pending 命令是否为空决定是否显示引导。
- `ui/chat/chat.css` 负责空态层与 AI 标识的层级和位置；空态层不拦截手势，不新增会话状态。

## 验收场景

1. 从工作区新建会话后，顶部显示“内容由AI生成”，页面消息区域中央显示“输入消息开始新会话”，两者不重叠。
2. 已有会话加载完成但没有消息时，在消息区域中央显示“暂无消息”。
3. 首条 pending 或服务端消息出现后，空态引导消失，消息按原逻辑展示并可滚动。
4. 深色主题、浅色主题、窄屏以及输入框展开后，引导仍以顶部栏与输入框之间的可用区域为基准居中。
