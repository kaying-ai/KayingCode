# 3.17.2 UI 同步边界

- 采纳本机文件打开方式、另存为、Office 链接安全与图片预览编辑等独立界面更新，平台操作继续通过 IPlatformService。
- 轮尾普通加载采纳上游 3.17.1+ 的像素光点、「工作中」与十分之一秒计时（见 `chat-loading-indicator.md`）；`apiRetry` 仍优先，等待交互或 active work 阻塞时继续隐藏。
- 预览卡片主体、键盘激活与「打开」按钮共用同一个预览动作；下拉菜单不触发预览，一次点击最多产生一次导航。保留现有文件校验、远端 identity 与自动打开投影。
- 保留现有会话/草稿/投影 owner、设置 Source authority、内置与本地插件界面、置顶拖拽反馈和模式文案；不恢复已移除的订阅、分享、旧插件面板或官方云目录入口。
- 上游整套 data-sync/settings-scope 替换依赖不同的服务组合，本轮作为产品差异排除；现有同步协议与可用入口保持一致。
- 图片源字节只读，标注状态归预览组件；发送到输入框必须通过当前 Composer 已有附件入队端口，捕获的 receiver 释放后拒绝迟到提交，不改写其他任务草稿。

```text
预览状态 → 捕获 Composer receiver(scope) → 异步 PNG 导出
                           ↓ scope 释放即失效      ↓
                  拒绝迟到结果 ← 校验 receiver → 既有附件队列
```

- 验收：类型/Lint、现有侧栏/模式回归、文件动作与图片编辑浏览器场景；无对应系统应用的环境应显示现有不可用状态。
