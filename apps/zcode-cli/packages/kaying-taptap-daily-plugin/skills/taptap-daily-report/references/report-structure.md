# 日报固定结构

## 01 今日速览

3–5 条，只写报告内可核验的信号：新游数量、榜单头部变化、最拥挤赛道。

## 02 新游发现

- 近 7 日首发/新开预约/测试总量。
- 首发 Top 20：图标、日期、游戏、赛道、类型、预约、评分、厂商、来源。
- 新开预约 Top 20：列同上。
- Top 6 深度解读：一句话定位、目标用户、可比产品、信号、风险、置信度、证据。

## 03 热门游戏

- 下载/热门榜、预约榜、热玩榜各 Top 20（附录保留 Top50），表格列：图标、名次、游戏、赛道、评分、预约、变化、来源。
- 榜单洞察：结构变化、异常升榜、交叉上榜。
- 排名变化 Top 10：与上一份快照对比，表格列：图标、游戏、变化。
- 跨榜游戏：表格列：图标、游戏、上榜情况。

图标取 `iconUrl`，展示为 28×28 缩略图；缺失时显示 `—`，不阻断报告。

## 04 题材赛道

固定 12 个赛道：二次元、策略/SLG、卡牌、MMO、模拟经营、休闲/益智、射击、竞技/MOBA、开放世界/RPG、独立游戏、小游戏、其他。

表格列：

| 列                       | 含义                                                |
| ------------------------ | --------------------------------------------------- |
| 7日新游                  | 最近 7 日该赛道首发唯一游戏数                       |
| 30日新游                 | 最近 30 日该赛道首发唯一游戏数                      |
| 7日预约                  | 最近 7 日该赛道新开预约唯一游戏数                   |
| 三榜占比                 | 三榜 Top50 去重集合中该赛道游戏占比（多标签可重复） |
| 拥挤度                   | 0–100 相对指数                                      |
| 等级                     | 低 / 中 / 高                                        |
| 供给分 / 榜单分 / 预约分 | 三个分量的百分位分数                                |

拥挤度公式：

```text
供给分 S = percentile_rank(newGames30d)
榜单分 L = percentile_rank(boardShare)
预约分 R = percentile_rank(newReservations7d)
crowding = round(0.45*S + 0.30*L + 0.25*R)
```

数据不足时显示 `—` / 未知，不按 0 分处理。

## 05 机会与风险

事实与推断分开；每条带 evidenceId。推断必须明确标注。

## 06 数据说明

- 报告日期、采集时间、数据窗口。
- 榜单与新游口径。
- 日历覆盖天数。
- 质量警告（降级、缺失、接口失败）。
- 模型只写解读，数字来自 snapshot/metrics。

## 07 附录

- 三榜完整 Top50。
- 证据索引：evidenceId、类型、URL、原始文件。
- 页脚三段：更多报告联系 service@kayingai.com；由 KayingCode kaying-taptap-daily 生成；开源一站式游戏开发Harness https://kayingai.com。
- Hero 右侧固定展示“加群交流”客服二维码卡片。
