# Windows 签名材料

仓库不保存签名私钥、证书口令或可直接用于发布的签名材料。Windows 打包优先使用外部环境的 `WIN_CSC_LINK`/`CSC_LINK` 及对应口令。未提供环境证书时，读取此目录下用户创建的 `windows-signing.local.json`；可复制 `windows-signing.example.json` 后填写绝对 PFX/P12 路径及口令。该本机文件被 Git 忽略，但口令为明文，须限制本机访问权限。配置文件存在但无效时，打包会在构建前失败；未提供任何证书时，日志报告 `windows-unsigned`，产物只用于本地开发，不进入正式发行。

旧仓库曾跟踪开发证书私钥；即使它不进入新的 Git 历史，仍须由证书所有者完成吊销、替换和影响评估。正式发布使用仓库外密钥存储注入的新证书，并对最终安装包单独验证签名。
