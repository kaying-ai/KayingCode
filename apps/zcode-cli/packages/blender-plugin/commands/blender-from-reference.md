优先使用本消息的图片、用户路径和当前工作区里的参考。先对齐姿势、比例和主要轮廓，自行渲染草模、对照参考、局部修正并复看，在同一轮继续细化和交付。生成服务不可用时走可行的本地路线，最终交付实际预览、文件和剩余差距。用户明确要求分阶段验收时按约定暂停；其余情况只在关键输入缺失或授权确实阻塞时询问。
