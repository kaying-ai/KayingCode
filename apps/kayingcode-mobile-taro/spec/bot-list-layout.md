# 小程序 Bot 列表卡片图标布局

## 产品规则

- Bot 卡片左侧后端图标、右侧当前项选中图标和编辑图标都以卡片内容区的垂直中心为共同基线。
- 当前项选中图标与编辑图标组成同一个右侧操作组，组内使用 `align-items: center` 对齐；两者字形中心必须处于同一水平线。
- 图标居中不能依赖文字内容的行数。标题、状态、远端地址或错误信息增加卡片高度时，图标继续相对整张卡片垂直居中。
- 左侧后端图标保留 26px 视觉尺寸，选中图标保留 18px 视觉尺寸，编辑入口保留现有 36px 触控盒；布局修复不缩小小程序触控目标。

## 状态与接口

- `ui/botList.tsx` 继续消费当前 Bot、连接状态与错误信息；本调整只改变图标节点组织和样式，不新增选择状态。
- `ui/shell.css` 负责图标盒、右侧操作组和卡片的交叉轴对齐。Bot 选择、重命名和左滑删除的事件路径保持不变。

## 验收场景

1. 当前 Bot 卡片显示后端图标、选中图标和编辑图标时，三者相对卡片垂直居中；选中图标与编辑图标水平对齐。
2. 当前 Bot 卡片包含多行远端地址或错误信息时，三个图标仍在整张卡片中心，不回到顶部。
3. 深度主题、浅色主题和窄屏下图标盒不互相挤压，编辑按钮触控区域保持 36px。
4. 非当前 Bot 卡片仅显示后端图标和编辑图标，二者仍垂直居中；选择 Bot、重命名和左滑删除继续可用。
